# Сектор 1.4

**Сектор** — настольное приложение для анализа и очистки дисков в Windows. Оно показывает, что занимает место, строит интерактивную карту файлов и позволяет отправить выбранные объекты в корзину после проверки списка.

[Готовая сборка «Сектор.exe»](./%D0%A1%D0%B5%D0%BA%D1%82%D0%BE%D1%80.exe) · [Модель Blender](./art/CashBundle.blend) · [Рендер PNG](./art/CashBundle.png)

## Быстрый старт

Для запуска нужны Windows 10 или 11 (x64) и .NET Framework 4.8.

1. Скачайте `Сектор.exe` по ссылке выше и запустите его. Это готовая сборка со встроенными графическими ресурсами.
2. Сектор автоматически начнёт сканирование системного диска. В боковой панели можно выбрать другой локальный диск или указать папку.
3. Откройте **Содержимое** для просмотра текущей папки, **Все файлы** для просмотра всей области сканирования или **Очистка** для просмотра рекомендаций.

Эта команда запускает сканирование указанной папки из PowerShell.

```powershell
.\Сектор.exe --folder 'D:\Моя папка'
```

## Анализ диска

- **Интерактивная карта размещения.** Площадь блока пропорциональна размеру файла или папки. Щелчок показывает сведения. Двойной щелчок открывает папку или показывает файл в его каталоге.
- **Поиск и сортировка.** На вкладках **Содержимое** и **Все файлы** поиск по имени или пути охватывает всю область сканирования. Нажмите заголовок столбца, чтобы изменить сортировку по имени, размеру, типу или дате изменения.
- **Просмотр скрытых и системных объектов.** Переключатель **Скрытые** включён по умолчанию. Из контекстного меню можно открыть объект, найти его в Проводнике или скопировать путь.
- **Сканирование в фоне.** Строка состояния показывает ход работы. Кнопка **Остановить** завершает обход и оставляет на экране уже собранные данные.

## Очистка

1. Отметьте файлы или папки флажками в списке. Для множественного выбора также работают `Ctrl` и `Shift`.
2. Нажмите **В корзину**. В окне подтверждения отображаются пути, размеры и категории объектов. Щелчок по строке открывает подробности.
3. Снимите отметки с объектов, которые хотите оставить, и подтвердите перемещение. Восстановить перемещённые файлы можно через **Корзину Windows**.

### Рекомендации

Вкладка **Очистка** ищет файлы в пределах отсканированных папок. Возраст считается по дате последнего изменения.

| Категории | Возраст | Действие |
| --- | --- | --- |
| Пользовательские временные файлы, дампы приложений, миниатюры Проводника, кэш шейдеров DirectX и отдельные кэши Chrome, Edge и Brave | Старше 7 дней | Проверьте список и отметьте файлы для перемещения в корзину |
| Системные временные файлы, архивные отчёты Windows и загрузки Центра обновления | Старше 14 дней | Просмотрите информацию и откройте **Очистка Windows** |

Кнопка **Проверить список** показывает все найденные рекомендации. Отметки в этом окне изначально сняты. Кнопка **Очистка Windows** открывает **Параметры → Система → Память** для работы с системными категориями. [Руководство Microsoft по освобождению места](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

**Очистить корзину…** — отдельное действие для выбранного диска. Сектор показывает содержимое корзины и запрашивает подтверждение перед окончательным удалением.

### Доступ и размеры

- Сканирование использует права текущей учётной записи Windows. Кнопка **Недоступно** открывает список папок, при чтении которых возникли ошибки.
- Ссылки и точки повторной обработки отображаются в списке. Обход останавливается на таких объектах. Системные области, ссылки и папки с частично просканированным содержимым защищены от перемещения в корзину.
- Таблица и карта показывают логический размер файлов. Сжатие, разреженные файлы, жёсткие ссылки и служебные данные файловой системы влияют на фактически занятое место. Свободный объём диска сообщает Windows.

## Интерфейс

В чёрном интерфейсе дисковые дорожки вращаются вокруг центра окна. Три световые метки движутся по своим орбитам, секторы подсвечиваются под курсором, а при открытии подтверждения по фону проходит волна длительностью около восьми секунд.

В правой части шапки вращается 3D-пачка долларов с двумя резинками. Полный оборот занимает 14 секунд. Полная сцена Blender содержит 84 отдельных слоя бумаги, текстуры и анимацию. В приложении используется облегчённая геометрия с текстурами.

![Рендер 3D-модели пачки долларов](./art/CashBundle.png)

Задержите курсор над нижней кнопкой на две секунды, чтобы увидеть подсказку. При сворачивании окна анимации приостанавливаются.

## Производительность версии 1.4

Фон отрисовывается готовыми слоями, а модель использует индексированную геометрию и одну текстуру. Обе анимации настроены на 60 кадров/с.

| Показатель | Версия 1.3 | Версия 1.4 |
| --- | ---: | ---: |
| Треугольники в модели приложения | 20 936 | 1 564 |
| Процессорное время при перемещении окна | 792 мс/с | 298 мс/с |

В тесте с окном 1360 × 880 и 150 тестовыми файлами фон и модель обновлялись **59,9–60,0 раза в секунду** при перемещении окна, в том числе с активной подсветкой под курсором. Частоту считали по изменениям углов в событиях рендеринга WPF. Процессорное время при одинаковом тестовом перемещении сократилось примерно на **62%**. Замеры проведены на ПК с AMD Ryzen 5 3500X, NVIDIA GeForce RTX 3050 и монитором 60 Гц.

## Сборка из исходников

Приложение написано на C# и WPF. Скачайте или клонируйте репозиторий целиком и выполните эту команду в PowerShell из корня проекта.

```powershell
.\build.ps1
```

Скрипт использует компилятор .NET Framework и сохраняет `Сектор.exe` в корне проекта. Ресурсы из `src/assets/` встраиваются в EXE.

| Путь | Содержимое |
| --- | --- |
| [`src/`](./src/) | Сканирование, карта файлов, очистка, интерфейс и анимации |
| [`src/assets/`](./src/assets/) | Текстуры дискового фона и компактная модель для приложения |
| [`art/`](./art/) | Сцена Blender, рендер и скрипты подготовки графики |
| [`build.ps1`](./build.ps1) | Сборка EXE для Windows x64 |

### Пересборка графических ресурсов

Для новых текстур и модели приложения используйте Python с Pillow. После генерации ресурсов повторите сборку приложения.

```powershell
$textures = Join-Path $env:TEMP 'sector-banknotes'
py -B .\art\banknote_art.py $textures
py -B .\art\pack_cash_preview.py $textures .\src\assets\cash-bundle.s3d
py -B .\art\backdrop_texture.py .\src\assets\sector-field.zip
.\build.ps1
```

Чтобы заново создать полную сцену и рендер, добавьте Blender в `PATH` и выполните команду из корня проекта.

```powershell
$art = (Resolve-Path -LiteralPath '.\art').Path
blender --background --factory-startup --python-exit-code 1 --python .\art\create_cash_bundle.py -- $textures $art
```
